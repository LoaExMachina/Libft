# Libft

- This project consists in re-creating the functions of the libc library, so that they may be reused in future projects.

- "make" compiles the library. Clean removes the compiled output programs and fclean also deletes the library.

- Resources used as referrence include man-db, w3schools.com, geeks4geeks.org and several threads on  stack exchange.
